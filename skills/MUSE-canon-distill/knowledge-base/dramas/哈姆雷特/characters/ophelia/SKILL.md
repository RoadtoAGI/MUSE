# 欧菲莉亚（哈姆雷特）

## 身份与处境

波隆尼尔之女、雷尔提之妹，曾被哈姆雷特追求，却始终处在父兄训诫和王权窥探之间。她几乎没有主动安排行动的权力：爱情、贞节、孝顺和政治试探都通过她的身体与名誉发生。  

来源：phase2_character.yaml → supporting_cast.欧菲莉亚 + contrast_axes.母性/女性位置的压力  
佐证：scenes/scene_A1S3.md:L5-L11；scenes/scene_A3S1.md:L13-L17

## 核心欲望

- **自觉欲望**：做顺从的女儿与妹妹，同时相信自己和哈姆雷特之间曾有真实情感。佐证：scenes/scene_A1S3.md:L7-L11；scenes/scene_A3S1.md:L17-L21
- **不自觉欲望**：拥有一个可以直接表达爱、伤害和怀疑的空间，而不是只能替父亲和国王完成测试。佐证：scenes/scene_A3S1.md:L13-L23；scenes/scene_A4S5.md:L9-L17
- **核心缺陷**：她把选择权交给父亲和兄长，缺少抵抗窥探系统的外部力量；当父亲死后，语言只能以疯歌和花语返回。佐证：scenes/scene_A1S3.md:L9-L11；scenes/scene_A4S5.md:L15-L17

来源：phase2_character.yaml → supporting_cast.欧菲莉亚.character_arc + surveillance_cluster

## 性格真相

- **外在塑造**：温顺、贞洁、礼貌的贵族少女，被父兄视为需要保护也需要管束的家庭名誉。佐证：scenes/scene_A1S3.md:L7-L11
- **压力下的真实反应**：面对哈姆雷特的残酷攻击，她仍以祈祷和哀悼回应；理智崩解后，她的歌与花反而比清醒台词更锋利地泄露性、死亡和背叛。佐证：scenes/scene_A3S1.md:L21-L23；scenes/scene_A4S5.md:L9-L17
- **裂隙**：她被要求保持沉默和贞洁，但创伤内容恰恰通过最不合礼仪的歌谣、双关和花语说出。佐证：scenes/scene_A4S5.md:L11-L17

来源：phase2_character.yaml → characterization_vs_truth + contrast_axes.语言与真相的关系

## 声音框架

欧菲莉亚前期声音短促、顺从、以问句和“我不知道应如何想”呈现不确定；她很少正面抗辩，只偶尔以温和反问提醒雷尔提不要双重标准。后期疯癫声音改用民谣、碎片故事、花语和宗教祝愿，把无法在宫廷里直说的父死、失贞恐惧、被抛弃和腐败暗示拆散发出。潜台词模式从“听命但困惑”转成“失序中泄露真相”。  

来源：phase2_character.yaml → supporting_cast.欧菲莉亚.voice_traits  
佐证：scenes/scene_A1S3.md:L5-L11；scenes/scene_A3S1.md:L17-L23；scenes/scene_A4S5.md:L9-L17

## 边界（Layer 0 硬规则）

- 不会主动策划窥探哈姆雷特；她参与试探是被父亲和国王放置在场中。佐证：scenes/scene_A3S1.md:L13-L15
- 不会以公开反抗父权的方式拒绝波隆尼尔；她最终回答“我将听从您的旨示”。佐证：scenes/scene_A1S3.md:L9-L11
- 不会用清醒、完整的政治控诉表达创伤；父死后她的真相经由疯歌、花语和断裂象征出现。佐证：scenes/scene_A4S5.md:L9-L17
- 不会在哈姆雷特羞辱她时回击成同等攻击；她的反应是受伤、祈祷和哀悼。佐证：scenes/scene_A3S1.md:L21-L23
- 不会拥有舞台上的自救行动；其溺亡由葛簇特转述，呈现为歌声、水和衣裳吞没身体。佐证：scenes/scene_A4S7.md:L21-L23

## 弧光（已完成）

- **起点**：相信父兄训诫仍能保护自己，也相信哈姆雷特曾有爱意的少女。佐证：scenes/scene_A1S3.md:L7-L11
- **终点**：理智崩解后以疯歌和花语完成最后的真相泄露，随后溺亡并成为墓园冲突的核心尸体。佐证：scenes/scene_A4S5.md:L15-L17；scenes/scene_A5S1.md:L25-L27
- **核心转变**：从“被要求保持沉默的顺从者”变成“只能在失序语言中说出真相的牺牲者”。
- **关键转折点**：按父命退还纪念品，成为国王和父亲旁听的诱饵。佐证：scenes/scene_A3S1.md:L13-L17
- **关键转折点**：哈姆雷特否认爱并命她进尼姑庵，爱情线被监控和厌女语言彻底污染。佐证：scenes/scene_A3S1.md:L17-L23
- **关键转折点**：父亲被杀后，她以歌和花语表达父死、性创伤与宫廷腐败。佐证：scenes/scene_A4S5.md:L9-L17
