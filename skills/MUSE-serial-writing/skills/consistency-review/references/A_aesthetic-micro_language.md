# 句级表达与独白判读

本指南用于 A 组已经定位的搭配、指代、重复与长段表达疑点。先读前后文，判断信息、语气、节奏和人物作用；具体搭配可新颖，直接说明也可有效。

| subkind | 需要说明的决定性问题 |
|---|---|
| false_literary_diction | 修饰语与对象的关系不成立，读者无法还原所写的动作或感知 |
| sensory_mismatch | 感官关联造成误解；通感有可理解的关系时合法 |
| abstract_judgment_without_action | 判断缺少当前叙述所需的依据或指代；不要求抽象判断一律改动作 |
| stock_speech_tag | 语气标签只是重复已有语气，没有归属、音量、态度或节奏作用 |
| weak_character_expression | 弱否定或状态句在当前语境遮蔽必要信息，或机械填充对白间隙 |

“他低声说”在会被隔壁听见的场景中交代音量，不能按库存词删掉；连续多次写同一音量、上下文也未变化时可定位冗余。“她没有看他”可以表达拒绝，不能仅因否定句式要求改成动作。删除后比较信息、关系、节奏是否损失；删不掉却仍含糊的句子应澄清，不默认补手势、杯子或视线。

## 长独白

看独白是否改变人物之间的行动关系、读者对既有事件的理解，或形成作品需要的情绪与思想过程。重复已知内容且没有新的作用时，指出重复位置及其拖延的事件。重新解释前文、直接争辩、证词、悼念或抒情各有成立条件，不用数量投票，也不要求沉默结尾。

例如，重复“战争很残酷”的独白可能停在泛论；同样长的讲述若揭示说者曾参与某件事，使其先前的回避获得新含义，就改变了当前关系和读者理解。可迁移的是新增作用与可信来源，故事题材和收尾形式无需复制。

每条 finding 写当前精确原句、具体失败关系及建议方向。仅有阅读偏好时标明主观观察交作者；章级 reader 反馈由 reader-feedback-revision 处理，不额外回派 A 组构建豁免审批。
