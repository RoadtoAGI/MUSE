# 对白的作用与诊断

麦基《对白》讨论信息暴露、推进、人物塑造、差异、意义与节奏等作用。一个回合可以同时承担多种相容功能，作品与人物处境决定组合。

## 从当前交流判断

说话受可见刺激、主动追求、合作意愿、关系代价、共享知识与语言能力共同影响。下一回合需要与此前交流相容；回避、拒绝、静默、误解与坚持都可以成立。压力不必统一表现为短句，熟练者也可能更克制。

| 实际问题 | 判断与修复 |
|---|---|
| 重复没有作用 | 删除后信息、关系、节奏及声线都不变时可删。复述用于确认、压迫、仪式或讲述时保留 |
| 台词只为交付作者解释 | 场内对象与人物需要无法解释这段话时，改其来源或承载；教学、报告、辩论与自省可以直接阐述 |
| 交流无法理解 | 检查听者能否恢复省略与指代；隐语需有共同语境、隔听需求或故意误导等条件 |
| 声音失去人物依据 | 回到经历、关系与注意方式；共享行话、礼节或局部句式相似不直接判错 |
| 超出自知或语言能力 | 核实来源、训练及当前状态，恢复人物可知范围；不能仅因台词条理清楚就判错 |

## 删除测试与边界例

“最小充分回应”指删去无功能部分，保留人物目的、理解、关系、表达和节奏所需内容。例如日常争执中，“那着火了你也等审批？”可能完成反击；听证记录要求交代推理时，完整说明前提与结论更适合。决定性差异是交流目的和共享语境，句长本身不决定好坏。

归谬用于人物愿意反驳、对方前提可被推至难以接受后果的情境。直接否认、追问、承认局部、离开或合作也可成立；按角色与现场选择，不按技巧轮换。

“我会先……再……”可能是人物在制定计划，也可能是作者预告尚未发生的表演。只有后者在替代当前场面、且未承担人物交流作用时才需要改写。

修订落在已定位问题上。动作、直陈、间接表达或叙述均可实现目的；不能把所有解释机械改为物件、沉默或碎句。
