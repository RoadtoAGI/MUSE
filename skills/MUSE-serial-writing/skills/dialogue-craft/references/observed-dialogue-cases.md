# 审阅到修订的实际观察（对白层）

用于判断多人对白的声音差异、台词是否替读者结算因果，以及说话归属的写法。沿 [dialogue-craft](../SKILL.md) 的判据使用。来源均为 MUSE 真实运行产物（`StoryStudio/results/writing-bench/<model>/<timestamp>/<qid>/pipeline/`），2026-10-03 逐字核对；“快照对”指对一段多处改动的归纳。标注“作者改稿”的几条取自作者在长篇《帝国雄心》里对模型初稿的亲手改稿，原文取自 StoryStudio 的 git 提交，改前稿未入库的注明据修改记录。

## 多人共用同一套语域

**合规语域覆盖人物声音**（gpt-5.6-sol/20260830_230000/594 问讯与暂扣；语义审计 character_voice：职业、处境和权力位置不同，语言却共享同一套范围限定、证据归属、责任拆分和复述确认句式；快照对）。

- 修订前：“当天还有谁接触过这批材料？” ⏎ “原登记放在这里，我按页回答。您的比对结果另记。” […] 罗葵站到门边，没有立即走：“暂扣依据已经念清。齐音，你听见了？” ⏎ “听见了。”齐音把印章收进掌心，“我的口头说明另页保存，原登记不改。”
- 修订后：“我问的是人。”祁序把她的图拨到地上。 […] 齐音伸手去取记录纸。警员按住她肩膀，她仍把每个字念出来：“长期识别，删掉。提供通行，写明是回水抢修。你们记录的是自己的话。” […] 罗葵弯腰捡起工单图，红铅笔的笔芯已经断在地上。“她右腕有旧伤。换边。”

决定性差异：修订前每个人都用“按页回答、另页保存、依据念清”的记录式句法；修订后审查者打断并抢先定性，当事人纠正具体字词，第三人只说工位判断。暂扣、登记页对照、代签等情节信息保留。

**轮流表态：职能 + 风险条款**（同 run 住户会；读者“多数住户只以职能和风险条款出现，我难以对具体的人形成持续关切”；快照对）。

- 修订前：机油住户又看了一遍巡检章：“我只修排水泵。工具自己带。进站记录若送到厂里，我的维修证保不住。箱子和纸都别交给我。” ⏎ 诊所勤杂工把配给凭条推回齐音面前：“我只认许静兰那一页。审查来问，我会说在哪次清点见过；诊所账册可能被扣。”
- 修订后：“我女儿的冬粮还押在厂里。”老马把借来的手套放回桶沿，“排水泵我修。纸别往我身上塞。” […] “我十六岁在码头夜校烧炉子，见过这个名字。”勤杂工用冻裂的指头比出欠账栏的宽度，“后来那张账涂黑了，我怕记错。”

决定性差异：每位住户依次按“我只……／风险条款／被查后果”表态，改为各自说出具体代价与来历；“只担一项、不进站”的有限承诺保留。与 [同类反应按人头轮流结算](../../prose-craft/references/observed-action-cases.md#同类反应按人头轮流结算) 是同一机制的对白面。

## 台词替读者结算因果

（gpt-5.6-sol/20260903_210000/594 S10；A 组）黎颂刚读出的时点与改路位置已足够重建次序，乔霖又替受害者结算责任：“先封门，后给活人换路。”“黎曼、乔岚，还有杨青，被记成没按路线走。”→“黎曼、乔岚、杨青。”乔霖扶住画框。水从她的手肘滴到画背，没有一滴落在画面上，“先签这两行，再谈谁没按路线走。”只念名字，动作承担态度。

（gpt-5.6-luna/20260829_000000/183 S07；A 组）玻璃、距离、拉门与后撤已经呈现“记得但不被许可接近”，对白又复述一遍并宣布结论：“你记得我。”我说，“记得排期，记得这栋楼，也记得要把事情做完。记得我，不能替你打开这扇门。我不会进会议室。”→“你还记得我。”我说，“我不进会议室。水在门外，别追过来。”

（作者改稿，长篇《帝国雄心·中途岛战役》，StoryStudio 提交 27a3260、23b93bd）要不要追击带伤的美国战列舰，在场参谋都看得出理由，初稿让近藤替读者讲了一遍：“烧成这样，用不着雷达也找得到她。这条船跑不到十节，后头那条更慢。今夜放她们回珍珠港，修好了，明年还要拉出来跟大和对射。”→“她烧成这样，瞎子也能看得到，用不着雷达了。而且这条船跑不到十节，爬也比她爬得快。”理由删去，换成一句挖苦，追击的决心和对对手的轻视都在话里。

## 台词只报情况

**汇报腔换成冲着处境说**（作者改稿，长篇《帝国雄心·瓜岛》，改前稿据 2026-10-20 修改记录）。陆战队登陆后滩头还挨着日军榴弹炮的轰击，前敌指挥官托马斯从前沿给师长打电话。

- 修订前：“一百五十毫米，榴弹炮。巡洋舰报告打掉了七八门，它们还在打。”
- 修订后：“是一百五十毫米榴弹炮。”托马斯说，“巡洋舰不是说打掉了吗？你听听，我这里还在落炮弹呐！”

决定性差异：同样的事实，修订前是在报情况，修订后是在向对方讨说法：反问点破巡洋舰的战报不实，“你听听”把听的人拉到自己挨炸的处境里，火气和要求都在话里。修订前的“一百五十毫米，榴弹炮。”也是记录体碎句，见 prose-craft 口癖模式库的“姿态句”。

**名著原文**（《日耳曼涅槃》第418章《争执》）。哈尔德指责希特勒不懂指挥，希特勒回道：“你在前线和法国人打过仗吗？你感受过法国人的战斗意志，体会过士兵长期连续高强度作战的辛苦和疲倦吗？”希特勒摘下胸前的一级铁十字勋章，将它在桌面上敲得梆梆直响，“我可是在前线和他们打了4年交道！……”两句反问冲着哈尔德有没有资格评价自己去；摘勋章敲桌把四年前线资历变成桌上的实物，删掉它读者就少了他当面拿资历压人的做法，这个动作不是填充。

## 说话归属与状态标签

全库审阅记录中没有读者因分不清谁在说话而投诉的案例；被修订的是状态标签与孤立的说话动作（均来自 A 组或 L1 lint），不宜据此认为“归属不清”是常见失败。

- 状态标签重复引语已表现的内容（gpt-5.5/20260526_120000/594 S02；A 组 stock_speech_tag）：秦执俯身看刻度窗。“复校。”他把笔帽合上，声音仍旧平稳，“东墙范围扩大到检修井上下各一米。……”→ 删去“声音仍旧平稳，”，归属由“他把笔帽合上”的动作和引语内容承担。同类：“他道，声音仍是一贯的平缓，一字一顿，”→“他道，一字一顿，”（claude-opus-4-7/20260614_200000/184 S01）。
- 孤立的说话动作短段（同 run S05；L1 lint）：“红章落下去。 ⏎ ‘废料车放行。……’秦执收回表格，”→“红章落下去，秦执说：‘废料车放行。……’他收回表格，”。动作并入引语所在段，说话人先于引语落位；红章动作与两句命令保留。改动前提是该动作本身没有独立停顿作用；有作用的短段按节奏保留。
- 作者改稿，开口的外形标签删掉，或换成处境里的心理（长篇《帝国雄心·中途岛战役》，StoryStudio 提交 27a3260、23b93bd）：
  - “近藤放下望远镜，嗓音发紧：”→“近藤放下望远镜：”，同一处的台词改动见“台词替读者结算因果”。
  - “‘是我写的。’她开口很轻，前排的人都往前探了探身子”→“她怀着愧疚开口”。史密斯接着说“多出来的那一票也许就是我的”，读者要带着她的愧疚去读这句；“开口很轻”只交代了音量。
  - 宇垣问松田凭什么把美国航空母舰摆在中途岛东北。初稿“松田不慌不忙地说”，作者先改成“冷静地说”，随后又否掉：松田在图上演习里刚找出整份计划的漏洞，像发现了零日漏洞，镇定的姿态和处境相反。经作者批准的定稿：“松田等的就是这一问：‘参谋长，你们一炸中途岛，美国人还用得着去找你们的航空母舰吗？’”开口前一拍心理从处境推出，台词改成冲着宇垣的反问。

  决定性差异：写音量、音色、语速的标签删掉；台词需要读者知道说话人此刻的心理时写出心理，这份心理要从人物当时的处境推出，“冷静”一类默认的镇定姿态同样是套话。
- 名著原文，开口前一拍心理由眼前的刺激推出（《日耳曼涅槃》，据 MUSE-canon-distill 知识库所收全文）。第78章《婚约》，老齐亚诺谈造船收益时说“这对我们两家、不，是一家而言，都是再令人欣喜不过的局面”，“方彦心中猛然震动，忍不住脱口而出道：‘齐亚诺叔叔，你已经同意我和西尔维娅之间的婚约了么？’”心理的来由是对方一个改口。第532章《筹备》，“丘吉尔心里略微有些不忍，但看到海陆两位军头的冷淡目光之后，立即就被坚定漠然所取代”，接着坚持把双发轰炸机派去直布罗陀：心理随在场两人的态度转向，后面那段台词的强硬由此而来。
- 同作的全稿清理（作者审定，提交 23b93bd）：删去“语气笃定”“语气生硬”“一字一顿地下令”“厉声下令”“嗓音发涩”“声音发沉”等二十余处；保留“扯着嗓子喊”（舰上失火，要压过噪声）、“金的嗓门隔着门传到走廊上”、参谋长把门关严后压低声音、守岛的人断水两天后哑着嗓子：这些声音交代了听见的条件或身体状态。
