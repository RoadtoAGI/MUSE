# 表达失真的判别与修订

本文件将常见表面形态按它损伤的叙事作用组织，供 writer 和既有审阅者按问题读取。相同词句可以有不同作用；统计与 family 名帮助定位，语义问题由当前正文及其上下文确认。修复保留事实、人物、声音、节奏与授权原文，不以零命中为创作目标。

## 信息与焦点

当前文字是否让读者获得本场所需的变化、感受或认识？判断时包括叙述声音、时间体验与意象作用，不能只看梗概是否少了事件。

| 候选形态 | 成立的问题与处理 | 合法相邻用法 |
|---|---|---|
| 主次失焦、动作清单、资产盘点 | 次要程序反复结算已知结果，关键变化被淹没；保留影响风险或选择的环节，收束其余 | 程序每步改变危险、盘点表达控制欲或生存压力 |
| psychological_overfill / explanation_after_action | 心理或解释只重说读者已完整得到的认识；删重复，保留新判断 | 反思重组先前意义，或叙述者的理解与读者形成差异 |
| 概括替代过程 | 场景承诺让读者经历发现，正文只宣布“震撼”；补理解所必需的过程 | 过渡、总结、回忆或有意压缩承担叙事功能 |
| 反复感知 / 碎片结算 | 看、听、停顿等句子既不改变感知，也无声线或节奏作用；合并同一作用 | 持续观察发现差异；重复形成等待、仪式或渐变 |

例如“他害怕”在险情后只复述刚呈现的恐惧时可省；向同伴直接说“我害怕”，使同伴接管危险操作时有新的关系作用。情绪命名本身不决定修改。

## 人物与叙述权限

核对说话者或视角人物当时能知道、理解和表达什么，叙述者另按既定权限处理。

| 候选形态 | 成立的问题与处理 | 合法相邻用法 |
|---|---|---|
| omniscient_overexposure / omniscient_underexposure | 无渠道地获得秘密，或省略使当前因果无法理解；修正供给或叙述 | 受限视角的未知、叙述者有意延迟揭示 |
| dialogue_as_author_solution | 人物突然掌握作者研究所得或替作者宣布结论；回查知识与目的 | 教授讲解、审讯推理、坦白与共同讨论有场内理由 |
| narrator_self_corrects / emotion_naming_under_face_loss | 无依据的自知或道德纠偏抹平已定认知；保留人物实际理解 | 反省由经历触发；有足够自觉的人物直接表达 |
| signature_voice_overuse / 身份隐喻 | 职业标签替代真实观察，隐喻持续无对象依据；回到当前关注和关系 | 已建立的比拟习惯、讽刺、专业概念改变理解 |
| grand_scene_grand_language | 只按事件规模预定情绪强度，人物与文体失真；回查现场条件 | 克制、延迟、激烈反应及档案体均可成立 |

潜意识分析留在作者层。人物不自知可以由稳定行为和信息差显现；不需要补一段自我诊断。故事信息缺失属于上游时，回交相应材料负责人。

## 表达组织

修辞、归属和段落的形态要与所表达的关系相符。不同方法有各自用途，不排统一优先级。

| 候选形态 | 成立的问题与处理 | 合法相邻用法 |
|---|---|---|
| contrastive_negation_assertion、抽象短语、库存比喻 | 无实际对照或映射，句式伪造新认识；补准确关系或省去重复解释 | 事实纠错、概念区分、误认修正、反讽及有据类比 |
| micro_punchline_cadence / ordinal_gravity_marker | 反复用短句或首次末次标记替事件宣布重要性；组织真实后果 | 断裂节奏、准确时间事实或声音中的强调 |
| state_persistence_template | 静止状态反复结算且无作用；合并 | 持续危险、等待或人物对稳定状态的执念 |
| 说话标签、强制对白收尾 | 同义标签循环替换、段落总靠开口结束且压扁节奏；按本段作用组织 | “说/问/答”、低声避人、听者反应、动作、纯对白均可使用 |
| 同源比喻、修辞密集、副词、精确计时 | 形态持续遮住对象与认识；选准关系和重心 | 母题回响、密集风格、测量或人物确实注意时间 |
| 长独白或均质分段 | 论点反复或分段遮断连贯关系；按认识变化组织 | 思想展开、故事转述、长句与单句段有独立作用 |

“他低声提醒岗哨就在门外”提供了音量的现场原因；将每轮“低声”换成“声音很低”仍维持同一重复机制。修复目标是消除失效作用，不是逃离检测词。

## 规划痕迹外泄（planning_trace_leakage）

设计字段交付事实、关系、意图、必要结果与实现候选。字段标题、理论标签或按任务表逐项结算进入正文，损伤人物经验与叙述连贯时，保留语义并重新组织表达。故事内的清单、档案或作者授权原文依既定内容契约保留。

有名著参考时，核对的是本作是否实现已采用的机制与必要结果。物件、动作、台词顺序仅属候选时可以替换、合并或省略；遗漏必要因果才须修补。正文有用的留白、长独白或冷感文体可由局部证据及其功能成立，设计字段的预声明只帮助解释。

## 复核与反馈

沿既有 finding 记录位置、实际原文、失效作用和修改范围。来源不足、上下文失真与执行偏离分别回交原环节；审美选择交作者。修后回读受影响语境，看重复或失真是否仍在，不用替换措辞证明完成。

[forbidden_migration_patterns.yaml](forbidden_migration_patterns.yaml) 保留脚本所用的同功能候选词表：contrastive_explanation、ordinal_significance、state_label_assessment、numeric_authority。出现“其实”“此刻”“全员”等只提示检查同一问题是否延续；本表不给这些普通词设普遍禁令，机器结论须按当前脚本策略及语义审阅解释。

## 作品管线的明确密度合同

下列阈值是本包已有作者裁决的发布约定，按 ai_policy 执行；不作为麦基理论或普遍文体标准。

### referential_vagueness（dummy_pronoun / demonstrative_classifier 两族）

- **group**: semantic_heuristic
- **cluster**: referential_vagueness
- **定义**：
  - dummy_pronoun（形式主宾语）：它/这东西/那东西占实词位——具体对象让位给模糊指称
  - demonstrative_classifier（指示限定词）：这/那+量词（这道/那把/这种）——名词已到位仍垫指示成分
- **密度合同（发布硬目标）**：修订后全文密度**严格低于名著基线**——dummy_pronoun 1.42/千字、demonstrative_classifier 6.11/千字。`wholetext_gate.yaml` 的 `density_contract` trigger 给出 `max_count`（预算上限）与 `required_reduction`（至少再减几处）；这与 severity 解耦，短文本两三处命中同样触发。
- **三级保留分级**（每处命中先定级再动手）：
  1. **protected / necessary**：删改会损伤指称功能——真特指对比（"这把（不是那把）"）、成品语境成立的拒绝命名装置（scene_card 可补强）（悬念/视角受限的未知物/拟物主体）、身份揭示的节奏控制。→ 保留，是预算的正当占用
  2. **legal-but-optional**：语义成立但可承前省略或实词复现（核对省略后指向、声音与节奏仍成立）。→ 默认省
  3. **pathological**：模糊指称无承载、模板性垫词、句内已有实词仍加指示成分。→ 必修
- **repair_strategy**（按序收敛，禁止跨族迁移）：
  - dummy_pronoun：承前省略（"嫌它响→嫌响"）> 实词复现 > 局部重构；**不得以指示词+名词兜底**（那会把 dummy 改成 demonstrative——挤气球）
  - demonstrative_classifier：删可选指示成分（"那把旧伞→旧伞"）> 普通定指（"这道口子→口子/伤口"）> 直写具体对象 > 局部改句；**不得以形式代词兜底**
- **超预算处置序**：先修 pathological → 再省 legal-but-optional → 仍超预算且剩余全是 protected/necessary → **不强改不放行**，status 报 ESCALATED 交人工（风格保护与发布目标冲突时 fail-closed，不为压指标毁 carrier）
- **交叉禁止（挤气球防线）**：dummy_pronoun 的修订不得新增 demonstrative_classifier 形态，反之亦然；修后两族密度都须在各自预算内
- **窄非触发条件**：对白引号内已由机器排除，不会出现在 hit 里；无需另行申报
